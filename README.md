# ⚡ TaskMaster PWA

A modern, offline-first task management application built with **React 19**, **Vite**, **shadcn/ui (Tailwind CSS v4)**, and **Progressive Web App (PWA)** architecture.

## 🚀 Key PWA & Technical Features

- **Offline-First Architecture:** Powered by **IndexedDB** via `idb` for complete client-side data persistence.
- **Background Sync & Service Worker:** Integrated Workbox service worker caching strategies via `vite-plugin-pwa`.
- **Installable Native Feel:** Web App Manifest configured for standalone mode on iOS (Safari) and macOS.
- **Adaptive UI:** Accessible drag-and-drop reordering with full dark/light theme persistence.
